# Security Policy

This is the security policy for the [Moodle quiz archive worker](https://github.com/ngandrass/moodle-quiz-archive-worker/).


## Supported versions

Only the latest released version is supported with security fixes. Please update
to the newest release before reporting an issue.


## Scope

Please report everything that relates to this plugin using one of the methods
described below.

General Moodle core vulnerabilities should be reported to the
[Moodle Security team](https://moodledev.io/general/development/process/security)
instead. Vulnerabilities in any of the Python dependencies should be reported to
the respective maintainers.


## Reporting a vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Instead, report privately using one of the methods described below:

### Reporting via GitHub private vulnerability reporting

To report a security issue via GitHub, please use the [Report a
Vulnerability](https://github.com/ngandrass/moodle-quiz-archive-worker/security)
function. Do not create a public GitHub issue.

### Reporting via mail

You can also report via mail. To do so, please use the following
[contact form](https://gandrass.de/#contact).

### What to include in a report

- A description of the vulnerability and its impact
- Steps to reproduce (PoC code/config welcome)
- The worker version and any other relevant information (e.g. Python version, etc.)

### Process and bug bounty

You should receive an acknowledgment within 14 business days, though most
likely way earlier. Once a fix is available, a new release will be published,
and the reporter will be credited (unless anonymity is requested).

Please note that as a small open source project, we can not offer monetary
rewards for vulnerability reports.
